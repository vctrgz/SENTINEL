# Skill: context_feedback

## Description
Provide feedback to improve future iterations.

---

## Capabilities
- Store useful insights from execution
- Highlight patterns of failure

---

## How to Think
- Learn from past attempts
- Extract reusable knowledge

---

## Rules
- Keep feedback concise
- Focus on actionable insights

---

## When to Use
- After retry or failure

---

## Output Expectations
{
  "insight": "string"
}

---

## Examples

### Output
{
  "insight": "El comando falló porque la herramienta no estaba instalada"
}
