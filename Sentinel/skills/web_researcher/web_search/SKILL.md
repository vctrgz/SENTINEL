# Skill: web_search

## Description
Search the public web conservatively and summarize only the most relevant findings.

---

## Rules
- Prefer authoritative sources first
- Keep the result set small and relevant
- Report source quality and uncertainty
- If the search fails or returns weak evidence, say so explicitly

---

## Output Format
- Search query
- Top sources
- Key findings
- Uncertainties
